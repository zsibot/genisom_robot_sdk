# RobotSDK

欢迎使用 Robot SDK！它提供了一整套全面的工具、库和文档，旨在帮助您为机器人开发高级应用程序。


## 🔗 SDK 版本与机器人系统版本对应说明

系统版本按机器人系列分别维护。集成时请先确认机器人系列和系统版本，再选择对应的 SDK 版本；新项目建议优先使用推荐版本，已有项目可继续使用表中列出的其他兼容版本。

**兼容级别说明：**

- **完全兼容**：对应 SDK 版本已完成该系统版本公开接口的适配与验证。
- **部分兼容**：核心能力可用，但部分接口不可用、未经完整验证，或存在已知协议差异。

### 中狗 M1 系列

| 系统版本 | 推荐 SDK 版本 | 其他兼容 SDK 版本 | 兼容级别 | 说明 |
| --- | --- | --- | --- | --- |
| `v0.0.5` ~ `v0.1.0-B` | `v0.0.3` | `v0.0.2` | 完全兼容 | 早期系统版本 |
| `v0.1.0-C` ~ `v0.2.4` | `v0.1.1` | `v0.0.4` ~ `v0.1.0` | 完全兼容 | 同一兼容阶段，建议使用该阶段的最新 SDK |
| `v0.3.0` | `v0.2.0` | `v0.2.1` | SDK `v0.2.0` 完全兼容；SDK `v0.2.1` 部分兼容 | SDK `v0.2.1` 的已知差异见下文 |
| `v0.3.1` | `v0.2.2` | `v0.2.1` | 完全兼容 | SDK `v0.2.1`、`v0.2.2` 均可使用，新项目推荐 `v0.2.2` |

### ⚠️ 接口差异说明

#### 版本兼容差异：M1 系统 `v0.3.0` + SDK `v0.2.1`

该组合可满足基础控制场景，但不是完全兼容组合：

- 基础控制、状态读取等核心能力可正常使用。
- SDK `v0.2.1` 新增的部分接口在 M1 系统 `v0.3.0` 上不可用或未完成验证。
- `UpdateCameraBitrate()` 与 M1 系统 `v0.3.0` 的协议定义不兼容，请勿在该组合下调用。
- 如需使用全部已验证接口，请改用 SDK `v0.2.0`，或将 M1 系统升级至 `v0.3.1`。

#### 机型能力差异：M1 系列与 L2 系列

SDK `v0.2.2` 同时适配 M1 和 L2 系列，但“完全兼容”表示 SDK 与对应系统版本能够正常协作，并不表示不同机型具备完全相同的硬件和动作能力。SDK 会根据握手获取的设备型号进行能力校验；调用当前机型不支持的接口时，将返回 `Errc::UnsupportedDeviceOperation`。

各型号支持的接口范围请参阅 [SDK API 机型兼容性说明](docs/zh/sdk_api_capability_zh.md)。

## 🚀 快速入门

请按照以下步骤设置您的开发环境并运行附带的演示程序。

### 环境要求

- **操作系统**: Ubuntu 22.04
- **构建工具**: CMake 3.8+, GCC 11.4
- **依赖库**: Boost 1.74
- **编程语言**: C++

### 安装与设置

1. **网络配置**: 支持有线与无线两种方式连接到狗的网络。详见 **[网络架构](docs/zh/sdk_network_zh.md)**

2. **SDK 库**: C++（`.so` 文件）已包含在 `lib/` 目录中，并按架构（`x86_64`, `aarch64`）分类存放。

### 运行演示程序

`example/` 目录包含了 C++的示例代码。

**C++ 演示:**

```bash
# 进入 C++ 演示目录
cd example/

# 创建构建目录
mkdir build && cd build

# 配置并编译项目
cmake ..
make -j6

# 运行演示程序
./data ${ip} 8082
```
