## 🔗 SDK 版本与软件平台版本对应说明

为便于维护，这里不再使用“平台版本 × SDK 版本”的大矩阵，而改为按**推荐版本 + 可用版本 + 差异说明**的方式记录。  
使用时请优先选择“推荐 SDK 版本”；仅当业务需要回退或复用现有集成时，再参考“可用 SDK 版本”和差异说明。

**兼容级别说明：**
- **完全兼容**：对应 SDK 版本已完成该平台公开接口的适配与验证。
- **部分兼容**：核心能力可用，但部分新增接口不可用、行为存在差异，或存在已知协议不兼容。

| 软件平台版本 | 推荐 SDK 版本 | 可用 SDK 版本 | 兼容级别 | 备注 |
| --- | --- | --- | --- | --- |
| 0.0.5 ~ 0.1.0-B | 0.0.3 | 0.0.2 ~ 0.0.3 | 完全兼容 | 早期平台版本 |
| 0.1.0-C ~ 0.2.4 | 0.1.1 | 0.0.4 ~ 0.1.1 | 完全兼容 | 同一兼容阶段，建议统一使用最新 SDK |
| 0.3.0 | 0.2.0 | 0.2.0, 0.2.1 | `0.2.0`：完全兼容；`0.2.1`：部分兼容 | 使用 `0.2.1` 时存在接口差异，详见下文 |
| 0.3.1 | 0.2.1 | 0.2.1 | 完全兼容 | 当前最新记录 |

### ⚠️ 接口差异说明

#### 软件平台 `0.3.0` 搭配 SDK `0.2.1`

SDK `0.2.1` 可用于软件平台 `0.3.0` 的基础控制场景，但不是完全兼容组合。

已知差异：
- 基础控制、状态读取等核心能力可正常使用。
- SDK `0.2.1` 中新增的部分接口在软件平台 `0.3.0` 上不可用或未完成验证。
- `UpdateCameraBitrate` 接口与软件平台 `0.3.0` 的协议定义不兼容，不建议在该组合下使用。

## 🚀 快速入门

请按照以下步骤设置您的开发环境并运行附带的演示程序。

### 环境要求

- **操作系统**: Ubuntu 22.04
- **构建工具**: CMake 3.8+, GCC 11.4
- **依赖库**: Boost 1.74
- **编程语言**: C++

### 安装与设置

1. **网络配置**: 支持有线与无线两种方式连接到狗的网络。详见 **[网络架构](docs/zh/sdk_network_zh.md)**

2. **SDK 库**: C++（`.so` 文件）已包含在 `lib/` 目录中，并按架构（`x86_64`, `aarch64`）分类存放。

### 运行演示程序

`example/` 目录包含了 C++的示例代码。

**C++ 演示:**

```bash
# 进入 C++ 演示目录
cd example/

# 创建构建目录
mkdir build && cd build

# 配置并编译项目
cmake ..
make -j6

# 运行演示程序
./data ${ip} 8082
```
