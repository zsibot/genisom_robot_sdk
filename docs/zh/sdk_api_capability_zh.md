# Robot SDK — API 机型能力表

## 适用范围

本文档列出 `SDKClient` 的全部公开 API，以及各 `DeviceType` 枚举值的接口支持情况。

能力符号：

| 符号 | 含义 |
|:--:|:--|
| ✓ | 当前 SDK 不会因该机型拒绝接口 |
| — | 已知不支持；SDK 会拒绝 |

> “✓”表示机型能力允许，不代表调用一定成功。接口仍可能受连接状态、控制权、机器人当前状态、参数和外设是否存在等条件影响。
>
> SDK 因机型拒绝接口时返回 `Errc::UnsupportedDeviceOperation`，详见 [SDK 错误码文档](sdk_error_zh.md)。

## 维护规则

1. 新增 `SDKClient` 公开 API 时，必须在本表增加对应行。
2. 新增 `DeviceType` 枚举值时，必须增加机型列或更新机型分组。
3. 新增内部机型门控时，应同步更新本表、接口文档和错误码示例。
4. 已知不支持的接口应返回 `Errc::UnsupportedDeviceOperation`，且不发送协议命令。
